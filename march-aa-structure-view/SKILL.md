# 古建构造关系轴测图（透明画法）

和 `march-aa-exploded-plate-skill`（分层爆炸图，讲「每层长什么样」）是姊妹技能：
本技能**不拆层**，而是把整栋楼当一件透明实体画出来，讲**构件怎么搭、力怎么传**。

## 铁律（先读这五条）

1. **不生成 AI 图**。全部用参数化几何 + 手绘风矢量线画出来，可复算、可复核。
2. **屋面是玻璃罩，被遮构件是浅虚线**。两者是同一套逻辑：透明是为了看内部，虚线是为了分清「看得见的」和「挡在后面的」。可见边画实线，被挡的边一律降为浅虚线——**不许所有线一个粗细**。
3. **朱红只给三样东西**：传力链、构件编号圆、檐口/戗脊这类主轮廓。朱红过量就廉价的。
4. **传力链必须有物理依据**：屋面 → 梁架/斗拱 → 柱/墙 → 台基。不要为了好看画一条穿过空腔的线。
5. **构件名用古建术语**（额枋、斗拱、挂落、平坐、腰檐、山花、撒头、金柱…），不要用「屋顶」「柱子」「墙」这种泛称当标注。

## 动手前先读 `references/lessons.md`

那份是踩坑清单（96 行，按返工次数排序）：屋面拓扑、遮挡与线型、相机可见面、标注锚点、
字体、改代码的安全做法、交付前自检表。**新画一张之前扫一遍**，能省掉大部分返工。

其中最容易犯的三条先记住：

1. **屋面用等参数矩形**（`[XL(t),XR(t)]×[-Y(t),Y(t)]`），不是「每带把檐口乘 t 缩小」——后者会画出折纸风筝。
2. **背面剔除只对实心体**（`kind=='body'`）；屋面/砖石/板片两面都画，否则近坡被剔掉只剩线筐。
3. **中文标注只能用 `font('hei')` / `font('kai')`**，`font('num')` 是拉丁字体，出豆腐块。

## 工作流

**给一张照片时（主用法）**：

```
① 量   analyze_photo.py --photo 照片.jpg --out draft.json
          → 主体框、长宽比、候选檐口线、对称度（只是测量值）
② 认   看照片逐项判：屋顶形式 / 檐数 / 平面 / 间数 / 斗拱 / 平坐 / 台基
          → 每项都要写 evidence + confidence，看不清就写 unknown（见 references/photo-to-json.md）
③ 确认 把「判断 + 凭据 + 不确定项」列给用户确认或修改（这一步不能跳）
④ 出图 structure_plate.py --json draft.json --out out/x.png
⑤ 复核 出图后回照片对一遍：檐口层数、开间数、屋顶形式、台基高度
```

**已有形制参数时**：直接写 job.json（`references/schema.md`）→ 出图 → 看 QA 行与图 → 交付 PNG + job.json。

命令（需要一个带 numpy+Pillow 的解释器；macOS 自带的 `/usr/bin/python3` 往往没有，
本机已验证可用的是 `/Users/louis/workspace/3D/.tools/pocket-city-venv/bin/python`）：

```bash
PY=/Users/louis/workspace/3D/.tools/pocket-city-venv/bin/python
$PY scripts/structure_plate.py --json assets/samples/ting_square_2eave.json --out out/ting.png
$PY scripts/structure_plate.py --json job.json --out out/x.png --ratio 9:16
```

依赖：`numpy>=1.20`、`Pillow>=9.0`（见 requirements.txt）。字体：内置霞鹜文楷（OFL），
系统字体缺失时自动回退，不会报错。

## 版式

- 画幅：`3:4`（2400×3200，默认）/ `4:3` / `1:1` / `9:16`。
- 左上一行标题（families 名 + 「· 构造关系轴测」）+ 两行说明；右上照片卡（可选）。
- 图上画编号圆标；**编号图例在图的下面**（两行横排），线型图例紧随其后。
- 底部：左下比例尺 + 标注（面阔/进深、视向）；**右下 logo**（`assets/brand/mark.png` + `march-aa`）。
- **不画传力路径**（已成约定），也不画长引线。
- 具体字号/线重/颜色见 `references/style.md`。

### 编号标注（最容易翻车的地方）

号按构件清单排，点按「实际绘制像素」算，徽标压在构件上，引线只兜底。
完整流程、取点规则、`callout_xy` 写法与验收标准见 **`references/callouts.md`**——
改标注前必须先读那一篇，不要靠预览图肉眼估坐标。

## 画法要点（改的时候别破坏这些）

1. 深度缓冲是**逐三角形重心插值**的真实深度（`_tri_fill` / `_zbuffer`），不是「每个面一个深度」——否则大平面（台基顶）会被自己判成被遮。
2. 线段按 14 段切分后逐段判定可见性（`_runs`），可见画实线、被遮画浅虚线。
3. **屋面不参与遮挡**（`_zbuffer` 跳过 accent 面）：屋面是玻璃罩，它下面的斗拱/槛窗要能读出来。
4. 面按远→近叠低 alpha 填色（body 30 / mass 108 / screen 78 / accent 20–52），体量靠叠加自然加深。
5. 轮廓线单独一遍：法向接近垂直视线的面描边——柱身、体量侧面靠它成形（`prism(slim=True)` 的面不画棱边）。

## 排版

字号按画幅自动缩放（`_ts(W,H)` 取宽高比的几何平均），四种画幅的视觉比例一致。
左侧「编号图例 + 传力路径说明」是一整块：图例解释 01…11 是什么，传力路径那块解释那条红线是什么。

## 已知限制（诚实说明）

- 歇山/庑殿的**山花、撒头只是近似**：形状对，细部（博风、悬鱼、戗脊兽）没有。
- 硬山山墙是素白三角面，没有砖石质感。
- 塔的腰檐是「环状坡」近似，转角起翘只有一档。
- 廊在 3:4 画幅里只占约 45% 高（长条主体受宽度限制），要更满就换 `4:3`。
- 桥只做单/多孔石拱，不做木梁桥、廊桥。

## 自检清单

- [ ] 传力链从屋面一路到台基，中间没有跳空
- [ ] 每个编号在图上有落点，且落点落在该构件上
- [ ] 被遮构件确实是浅虚线（不是所有线一样粗）
- [ ] 朱红只有传力链、编号、主轮廓
- [ ] QA 行是 `OK`；主体没有压标题/照片/落款
- [ ] 构件名用的是古建术语
- [ ] 照片来的图：出图后回照片复核过檐数/间数/屋顶形式

# 殿堂（歇山 / 庑殿 / 硬山）

- 家族键：`dian`；`params`：`style`、`bays`、`bay`、`depth_bays`、`bayd`、`brackets`
- 构件序：台基踏跺 → 檐柱（三面）→ 墙体槛窗 → 额枋 → 斗拱 → 屋架 → 屋面 → 正脊吻兽
- 传力链：屋面 → 屋架 → 斗拱 → 额枋 → 檐柱/金柱 → 台基
- 屋架隔榀画（`xs[1:-1:2]`），实心三角面会糊住内部
- 歇山 = 下部庑殿坡收到肩部 + 上部两坡夹山花；山花用 body 面，不要用 accent
- 屋面坡高按举高：`ridge = z1 + ey * 0.52~0.56`

# 构件类型速查（画法要点 · 判别 · 时代）

给 `params.components` 用的对照表。每个字段列出**取值**、**画法要点**、**看图怎么认**、**时代倾向**。
渲染时把选中类型的名字写进标注，例如「柱础（覆盆式）」「正脊鸱尾（唐式）」。

```json
"components": {
  "column_base": "fupen",        // 柱础
  "bracket":     "jixin",        // 斗拱
  "arch_beam":   "lan_e_pupai",  // 额枋/普拍枋
  "ridge_orn":   "chiwei",       // 脊饰
  "roof":        "wudian"        // 屋顶（见 typology.md）
}
```

---

## 1. 柱础 `column_base`

| 取值 | 画法要点 | 看图怎么认 | 时代 |
|---|---|---|---|
| `plain` 素平础 | 柱脚一块方石，与柱同宽，不雕 | 柱下只有一个薄方台 | 汉—唐早期，民间一直用 |
| `fupen` 覆盆式 | 倒扣的浅盆：上径=柱径，底径 1.4–1.6 倍，**侧面是一段外凸的弧**，不是斜面 | 柱脚像扣了个碗 | 唐—宋官式标配 |
| `lianban` 宝装莲瓣 | 覆盆上再雕一圈莲瓣，瓣尖朝下、瓣数 8–16 | 能数出瓣 | 唐—宋，多见于佛殿 |
| `drum` 鼓镜础 | 一段扁圆柱（鼓）+ 顶面平镜，比例矮胖，直径约柱径 1.3 | 柱脚是个鼓，上下都平 | 明清官式 |
| `xumizuo` 须弥座式 | 础本身做成小须弥座：上下叠涩+束腰 | 础有束腰 | 清，等级高 |

**代码**：`column(..., base_type=...)`；`fupen` 用 12 段圆环近似弧面，`drum` 用 `prism` 短柱 + 顶面，`lianban` 在覆盆外加 12 片薄瓣。

## 2. 柱身 `column_shaft`

| 取值 | 画法要点 | 时代 |
|---|---|---|
| `round` 圆柱 | 默认 | 各代 |
| `octagon` 八角柱 | 8 段棱柱 | 唐—宋（经幢、石柱） |
| `square` 方柱 | 4 段 | 民间、早期 |
| `suo` 梭柱 | 上细下粗，**中段略鼓**（用两段锥形或三点样条） | 宋以前 |
| `gualeng` 瓜棱柱 | 柱身竖向凹槽，像瓜 | 宋（江南） |

**代码**：`prism(..., n=4/8/12)`；梭柱用 `taper` 参数（上下半径比 0.85–0.92）。

## 3. 斗拱 `bracket`

| 取值 | 画法要点 | 看图怎么认 | 时代 |
|---|---|---|---|
| `yidou3sheng` 一斗三升 | 一个栌斗 + 三块横栱，**无出跳** | 只有一层、贴在柱头 | 汉—唐早期、民间 |
| `touxin` 偷心造 | 出跳 2–3 层，**跳头不设横栱**，只有华栱交叠 | 侧面看是一串十字交叉，没有横向的拱 | 唐—辽 |
| `jixin` 计心造 | 每跳跳头都有横栱（瓜子拱/令拱） | 每层都有横向短拱 | 宋—清官式 |
| `xiegong` 斜拱 | 45° 斜出的拱，平面呈米字 | 转角处有斜向构件 | 辽金 |
| `ruyi` 如意斗拱 | 网格状密集小斗拱 | 整片网 | 明清南方 |

**画法通则**：先画栌斗（最下层大方斗），再按出跳层数逐层向外挑 `proj`；计心造每层在跳头加一块横向短拱（宽 = 出跳间距 × 0.8），偷心造只画华栱不出横拱。
**代码**：`bracket_set(..., style='jixin'|'touxin'|'yidou3sheng')`。

## 4. 额枋与横向联系 `arch_beam`

| 取值 | 画法要点 | 看图怎么认 | 时代 |
|---|---|---|---|
| `lan_e` 阑额 | 柱头之间一道横木，断面近方 | 只有一道 | 唐 |
| `lan_e_pupai` 阑额+普拍枋 | 阑额上再叠一块**扁而宽的枋**（普拍枋/平板枋），比阑额宽出 0.1–0.2 | 斗拱坐在一块通长扁枋上 | 宋—清 |
| `e_fang` 额枋（清） | 断面变高（高宽比 2:1 以上），下加由额 | 上下两道枋 | 明清 |
| `dìfu` 地栿 | 柱脚之间的横木/石 | 柱脚有横联系 | 早期 |

## 5. 脊饰 `ridge_orn`

| 取值 | 画法要点 | 看图怎么认 | 时代 |
|---|---|---|---|
| `none` | 只画正脊本体 | 平的 | — |
| `chiwei` 鸱尾（唐） | **鱼尾形**：下宽上窄、尾尖**向内（朝脊心）卷**，无兽头，整体像一片立起来的鳍 | 两个对称的"逗号"背对背 | 唐 |
| `chiwen` 鸱吻（宋元） | 兽头**张口吞脊**，尾仍上卷；兽头比尾短 | 能看出嘴 | 宋—元 |
| `zhengwen` 正吻（明清） | 龙形，**背上插剑把**，尾向外卷 | 背上有柄 | 明清 |
| `wangshou` 望兽 | 脊端一只小兽，坐姿 | 小兽 | 明清（硬山/歇山） |

**代码**：`ridge_box(..., orn='chiwei'|'chiwen'|'zhengwen'|'none')`，三者共用「沿 x 挤出 0.13」的做法，只换 y-z 轮廓。

## 6. 屋顶 `roof`（详见 typology.md）

庑殿 / 歇山 / 悬山 / 硬山 / 攒尖 / 卷棚 / 盝顶 / 十字歇山 / 重檐。

## 7. 其他可标类型的部位

| 部位 | 类型 | 画法要点 |
|---|---|---|
| 踏道 | 垂带踏跺 / 如意踏跺 / 御路 | 有垂带=两侧斜石；御路=中间整块斜石带雕 |
| 台基 | 普通台基 / 须弥座 | 须弥座有束腰 |
| 墙 | 夯土 / 砖墙 / 槛墙 | 砖墙画砖缝，夯土画水平版筑线 |
| 窗 | 直棂窗 / 槛窗 / 支摘窗 | 直棂=竖条无格心；槛窗=格心 |
| 天花 | 井口天花 / 藻井 | 藻井=层层收进的斗拱 |
| 山面 | 山花+博风+悬鱼 | 悬鱼挂在博风板正中，鱼形 |

---

## 渲染时的写法

标注里带类型：`柱础（覆盆式）`、`斗拱（三跳计心造）`、`正脊鸱尾（唐式）`。
描述里可以只写关键差异：「唐式：鸱尾、无普拍枋、斗拱偷心」。

## v0.7（2026-11-27）

这一版的主体是**编号标注**——从「按高度猜锚点」改成「按真实绘制的像素算坐标」，并把规则写成规范；同时补了桥与一座金代殿堂。

### 编号标注（新增 `callout_xy` 体系）

- 每个样本可写顶层 `callout_xy`：`label → [x, y]`（分数坐标）。`[x, y]` 表示徽标直接压在构件上、不画引线；`[x, y, ax, ay]` 才画一条短引线指回锚点。
- 坐标不再靠估：新增 `scripts/fit_callouts.py`，先 `monkeypatch` 录制 `Canvas.poly`，再按**实际绘制顺序**栅格化得到 id 图，用顶点签名把像素匹配回构件 `part`，取「离锚点最近的该构件可见像素」写回 JSON。
- 修掉三个真因：① 编号曾按屏幕高度重排（与图例顺序错位）；② `_PART_KEYS` 关键词顺序让「墙体直棂窗」被识别成墙体；③ 本轴测里 `+y` 才是有门那一侧，金柱/柱础/额枋/梁架的锚点高度与朝向都调了。
- 徽标避让收敛为「宁可挤、不离开构件」：`rr = r_mark * 1.25`、`push = (rr - d) * 0.30`；构件完全不可见时才允许外移并画引线。
- 新增 `references/callouts.md`：三条铁律（号按清单顺序 / 点必须由像素反算 / 引线只兜底）+ 事故对照表 + 十类构件的可见像素实测 + 反例清单；`references/lessons.md` 加第 26 条；`SKILL.md` 重写版式章节并增「编号标注（最容易翻车的地方）」。
- 已按此流程重做 `hall_tang`（十点全部落位）与 `sansheng`、`qiao5`。
